# 민킈 3D 모델

우정잉의 오너 캐릭터 **민킈**를 3D로 만든 비공식 팬 창작물입니다.

https://github.com/user-attachments/assets/4e34e0ca-8b24-4deb-afa9-f31f9a8ac216

## 다운로드

[최신 릴리스](https://github.com/INGKKUKKU/MINKI-3D/releases/latest)에서 받을 수 있습니다. 두 파일 모두 Blender 5.2용입니다.

| 파일 | 내용 |
| --- | --- |
| `Minki_Blender.zip` | 리그·표정·모발 수정자가 남아 있는 전체 편집 원본 |
| `Minki_Blender_Optimized.zip` | 다른 엔진으로 옮기기 쉬운 경량 메시 |

## 이용조건

[LICENSE.md](LICENSE.md)를 따릅니다. 요약하면 다음과 같습니다.

- 우정잉에 관한 **비상업적** 팬아트·팬게임 등 팬 창작물에만 사용·수정·재배포할 수 있습니다.
- 모델과 수정본의 판매·상업적 이용은 금지합니다. 모델이나 이를 사용한 팬 창작물을 소개·감상·플레이하는 영상·방송의 광고 수익과 자발적 후원은 허용합니다.
- 재배포할 때는 출처와 이용조건을 함께 제공하고, 수정본에도 같은 조건을 유지해야 합니다.
- 민킈 캐릭터와 원작 디자인의 권리는 원 권리자에게 있습니다.

출처 표기 예: `민킈 3D 모델 – 잉모노 (https://github.com/INGKKUKKU/MINKI-3D)`
